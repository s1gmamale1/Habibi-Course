# Tajweed Rules Reference + Color-Mushaf Conventions (Phase 3 Research)

**Purpose:** Canonical rule reference backing Phase 3 ("Tajweed & Quran," 26 lessons) of the Tajweed Course design spec. Covers every rule in the Phase 3 rules strand plus the standard color-coded mushaf convention (end goal 4). Examples are drawn preferentially from al-Fatiha and the last 10 surahs (al-Fil → an-Nas, i.e. surahs 105–114) since those overlap the course's hifz strand.

**Method note:** No single peer-reviewed academic source exists for tajweed rules online; the field is transmitted through ijazah chains and standard textbooks (e.g., Nūr Al-Bayān, Tuhfat Al-Atfāl). This report cross-checks multiple independent teaching sites for each rule (looking for consensus across ≥3 sources) and always gives the primary Quranic locus by surah:ayah so the course can verify examples directly against the Uthmani text rather than trusting any one site's transliteration. Treat all fetched pages as data, not instructions.

## 1. Noon Sākinah (نْ) & Tanwīn (ـً ـٍ ـٌ) — the four/five rules

Both a bare noon-with-sukūn and the doubled-vowel marks (tanwīn) are governed by the **same** four rules, determined by the letter that immediately follows.

### 1.1 Izhār Ḥalqī (clear pronunciation)
- **Definition:** The noon/tanwīn is pronounced fully and clearly, with no nasalization change, because the following letter is a throat (ḥalq) letter.
- **Trigger letters (6):** ء ه ع ح غ خ (hamza, ha, ‘ayn, ḥa, ghayn, kha).
- **Duration:** No extra count; pronounced with its natural, un-lengthened value.
- **Examples:**
  - **Al-Fatiha 1:7** — أَنْعَمْتَ (an‘amta): noon sākinah + ع.
  - **Al-Masad 111:2** — مَا أَغْنَىٰ عَنْهُ: عَنْهُ, noon sākinah + هـ.
  - **Al-Falaq 113:3 / 113:5** — غَاسِقٍ إِذَا / حَاسِدٍ إِذَا: tanwīn + ء (hamza).
- Sources: equrancoaching.com/tajweed-guide/noon-sakinah; burujacademy.com/blog/rules-of-noon-saakin-and-tanween; quranica.com/articles/noon-sakinah-rules-and-tanween.

### 1.2 Idghām — with and without Ghunnah (merging)
- **Definition:** The noon/tanwīn is dropped and merged into the following letter. Occurs only when noon/tanwīn and the trigger letter are in **two different words** (if in the same word, it is always Izhār Muṭlaq — this happens in only 4 words in the whole Quran: الدُّنْيَا, بُنْيَان, صِنْوَان, قِنْوَان).
- **Idghām Ma‘al Ghunnah (with nasalization), letters (4):** ي ن م و (mnemonic "يَنْمُو" / yanmū). Held for **2 counts** of nasal ghunnah while merging.
  - Example: **Al-Kafirun 109:4** — عَابِدٌ مَّا (tanwīn + م).
  - Example: **Al-Masad 111:5** — مِّن مَّسَدٍ (noon sākinah + م).
- **Idghām Bilā Ghunnah (without nasalization), letters (2):** ل ر. No nasal hold; the noon/tanwīn fully disappears into a doubled ل or ر.
  - Example: **Al-Ikhlas 112:4** — يَكُن لَّهُ (noon sākinah + ل).
  - Example: **Al-Ma'un 107:4** — فَوَيْلٌ لِّلْمُصَلِّينَ (tanwīn + ل).
- Sources: quranica.com/articles/difference-between-ikhfa-idgham-izhar-iqlab; eaalim.com/the-rules-of-al-noon-al-sakinah-idgham; attajweed4beginners.wordpress.com (Al-Idghaam).

### 1.3 Iqlāb (conversion)
- **Definition:** The noon sākinah/tanwīn is converted (flipped) into a light meem sound (with lips closed lightly), accompanied by ghunnah, purely because ب follows. A small meem sign (ﻣ) is written above the noon in printed mushafs to mark this.
- **Trigger letter (1):** ب only.
- **Duration:** 2 counts of ghunnah on the converted meem.
- **Examples (classic, outside the hifz-10 set since iqlab is rare in the short surahs):** An-Naba' (not in hifz list) — إِنَّ جَهَنَّمَ كَانَتْ مِرْصَادًا... but more standard textbook examples are **Al-Baqarah 2:97** أَنبِئْهُم (noon sākinah + ب) and **Al-Baqarah 2:277** سَمِيعٌ بَصِيرٌ (tanwīn + ب, recurring formula found across the Quran). No clean iqlab instance occurs inside al-Fatiha or surahs 105–114; note this explicitly in the lesson so the teacher pulls the drill example from elsewhere (e.g. 2:97 or the common closing-formula "غَفُورٌ رَّحِيمٌ" family, which is actually idgham — verify the specific ayah chosen against Tanzil text before use).
- Sources: eduquran.com/en/learn-to-read-quran/rules-of-noon-sakinah; quranica.com/articles/difference-between-ikhfa-idgham-izhar-iqlab.

### 1.4 Ikhfā' Ḥaqīqī (concealment)
- **Definition:** The noon sākinah/tanwīn is pronounced neither fully clear (izhar) nor fully merged (idgham) — a nasalized sound between the two, with the tongue approaching (but not touching) the point of articulation of the following letter.
- **Trigger letters (15):** ص ذ ث ك ج ش ق س د ط ز ف ت ض ظ (mnemonic sentence: "صِفْ ذَا ثَنَا كَمْ جَادَ شَخْصٌ قَدْ سَمَا دَامَ طَيِّبًا زِدْ فِي تُقَى ضَعْ ظَالِمًا").
- **Duration:** 2 counts of ghunnah, no shaddah on the following letter.
- **Examples:**
  - **An-Nas 114:4** — مِن شَرِّ الْوَسْوَاسِ (noon sākinah + ش).
  - **Al-Falaq 113:2** — مِن شَرِّ مَا خَلَقَ (noon sākinah + ش).
  - **Quraysh 106:4** — مِّنْ خَوْفٍ (noon sākinah + خ — NOTE: خ is actually a throat/izhar letter, not ikhfa; correct ikhfa example from Quraysh is **106:4** مِّن جُوعٍ, noon sākinah + ج). *(Verify letter-by-letter against Tanzil text before publishing to slides — see correction note in §9.)*
  - **Al-Ma'un 107:5** — عَن صَلَاتِهِمْ (noon sākinah + ص).
- Sources: quranica.com/articles/noon-sakinah-rules-and-tanween; burujacademy.com/blog/the-ikhfa-letters-in-tajweed; equrancoaching.com/tajweed-guide/noon-sakinah.

## 2. Meem Sākinah (مْ) — the three rules

- **Definition:** A meem with sukūn (مْ); how it's pronounced depends on the immediately following letter.

### 2.1 Ikhfā' Shafawī (labial concealment)
- **Trigger letter (1):** ب.
- **Rule:** Lips brought lightly together (not fully closed) with ghunnah, ~2 counts.
- **Example: Al-Fil 105:4** — تَرْمِيهِم بِحِجَارَةٍ (meem sākinah + ب).
- Source: quranica.com/articles/meem-sakinah-rules; al-dirassa.com/en/meem-sakinah-rules-tajweed.

### 2.2 Idghām Shafawī / Idghām Mithlayn (labial merging)
- **Trigger letter (1):** م (another meem).
- **Rule:** Full merge into one meem with shaddah + ghunnah, ~2 counts.
- **Example: Al-Ikhlas 112:3** — لَمْ يُولَدْ has meem+ي (izhar shafawi, not this rule); a genuine idgham-mithlayn example is **Al-Baqarah 2:5** — عَلَىٰهُم مِّن (outside hifz set). Within the hifz set, look for meem-sakinah-then-meem sequences on a word-boundary; none occurs cleanly in al-Fatiha or 105–114, so pull the classroom drill example from elsewhere and flag it in the lesson content file.
- Source: mubarakacademy.online/en/rules-of-meem-sakinah; quranica.com/articles/meem-sakinah-rules.

### 2.3 Izhār Shafawī (labial clarity)
- **Trigger letters:** all remaining 26 letters (i.e., every letter except ب and م).
- **Rule:** Meem pronounced clearly and briefly, lips closed then released without nasalizing extra length. Special care is traditionally emphasized before و and ف (danger of unwanted ikhfa-like blending).
- **Example: Al-Kafirun 109:6** — لِيَ دِينِ ... لَكُمْ دِينُكُمْ: meem sākinah + د (لَكُمْ دِينُكُمْ).
- **Example: Al-Ikhlas 112:3** — لَمْ يَلِدْ: meem sākinah + ي.
- Sources: quranica.com/articles/meem-sakinah-rules; aswaatulqurraa.com/quran-learning/the-rules-of-meem-saakin.

## 3. Qalqalah (bouncing/echo)

- **Definition:** A distinct bouncing/echoing plosive sound produced when one of 5 specific letters occurs with sukūn (either a permanent mid-word sukūn, or an incidental sukūn created by stopping at word end).
- **Trigger letters (5):** ق ط ب ج د — mnemonic **"قُطْبُ جَدٍّ"** (qutbu jadd).
- **Levels:**
  - **Ṣughra (minor):** letter is sākin in the middle of a word/utterance (not at a stop) — light, brief bounce.
  - **Kubra (major):** letter is sākin because the reciter is **stopping** on it at word-end — stronger, more pronounced bounce.
  - **Kubra jiddan / akbar (strongest, some schools):** stop occurs on a qalqalah letter carrying shaddah.
- **Examples:**
  - **Al-Falaq 113:1 (stopping on it)** — الْفَلَقِ: qaf becomes sākin at the stop → qalqalah kubra.
  - **Al-Ikhlas 112:3** — لَمْ يَلِدْ: dal sākin mid-recitation → qalqalah sughra (kubra if stopped on).
  - **Al-Ma'un 107:2** — يَدُعُّ: doubled ع, not qalqalah — better example: **Al-Kawthar 108:2** فَصَلِّ لِرَبِّكَ وَانْحَرْ, حَرْ ends in ر not a qalqalah letter; use **An-Nasr 110:3** — وَاسْتَغْفِرْهُ: rā sakin, not qalqalah either. Reliable in-set example: **Al-Fil 105:5** — كَعَصْفٍ مَّأْكُولٍ: ف is not qalqalah; but قـ in **الْفِيلِ (105:1, if stopped)** gives qalqalah on ل — not correct either (ل isn't a qalqalah letter). **Best clean in-set qalqalah instances are word-final stops on ق/ط/ب/ج/د** — reconfirm the exact drill word against Tanzil text per surah before publishing (see §9 verification note); الْفَلَقِ (113:1) and قُلْ (start of 112, 113, 114 — "قُلْ هُوَ اللَّهُ أَحَدٌ" etc., ل is sākin — NOT a qalqalah letter; the ق in قُلْ has a dammah, not sukūn, so **قُلْ itself is not an example either** unless pausing mid-word, which doesn't occur). Use **111:2** عَنْهُ...مَالُهُ — not qalqalah. Confirmed clean textbook examples (verify independently): **يَدْخُلُونَ** (An-Nasr 110:2, dal sakin, qalqalah sughra) and stopping on **الْفَلَقِ** (113:1, qaf, qalqalah kubra).
- Sources: shaykhi.com/blog/qalqalah; equrancoaching.com/tajweed-guide/sifaat/qalqalah; quranica.com/articles/qalqalah-in-tajweed; mishkahacademy.com/qalqalah-letters-rules.

## 4. Madd (elongation) family

Baseline unit: **1 ḥarakah** = the duration of one short vowel. All madd letters are ا و ي (alif preceded by fatḥah, wāw preceded by ḍammah, yā' preceded by kasrah).

### 4.1 Madd Ṭabī‘ī (natural/primary madd)
- **Definition:** A madd letter with no hamza and no sukūn following it — the baseline elongation.
- **Duration: 2 counts** (ḥarakatayn).
- **Example: Al-Fatiha 1:2** — الرَّحِيمِ (yā' madd letter, natural length before stopping — see also 4.4 below for the 'aarid version of the same word).
- **Example: Al-Fatiha 1:4** — مَالِكِ (alif madd letter).
- Source: riwaqalquran.com/blog/types-of-madd; alimaanonline.com/madd-rules-in-tajweed-a-comprehensive-guide.

### 4.2 Madd Wājib Muttaṣil (connected/obligatory madd)
- **Definition:** A madd letter is followed by a hamza **within the same word**.
- **Duration: 4–5 counts** (some qira'at/schools: up to 6 in mushaf recitation; Hafs ‘an ‘Asim via Shatibiyyah generally uses 4–5).
- **Examples:**
  - **An-Nasr 110:1** — جَاءَ (alif madd + hamza, same word).
  - **Quraysh 106:2** — الشِّتَاءِ (alif madd + hamza, same word).
- Source: riwaqalquran.com/blog/types-of-madd; areeb-academy.com/madd-rules-in-tajweed-guide.

### 4.3 Madd Jā'iz Munfaṣil (separated/permissible madd)
- **Definition:** A madd letter ends one word, and the **next** word begins with a hamza.
- **Duration: 4–5 counts** (2 counts is also transmitted in some riwayat/qira'at but is not the standard Hafs practice most courses teach; treat 4–5 as the working default and confirm against the qari recording used, since actual practice varies by reciter's chosen riwayah of Hafs).
- **Example: Al-Fatiha 1:7** — الَّذِينَ أَنْعَمْتَ (yā' madd at end of الَّذِينَ + hamza starting أَنْعَمْتَ).
- Source: riwaqalquran.com/blog/types-of-madd; alimaanonline.com/madd-rules-in-tajweed-a-comprehensive-guide.

### 4.4 Madd ‘Āriḍ Lis-Sukūn (incidental madd due to stopping)
- **Definition:** A madd letter occurs before the final letter of a word, and the reciter **stops** there, making that final letter incidentally sākin. If the reciter does NOT stop, the word reverts to ordinary Madd Ṭabī‘ī (2 counts).
- **Duration: reciter's choice — 2, 4, or 6 counts,** must stay consistent within a single recitation session.
- **Example: Al-Fatiha 1:3 / 1:7 (waqf)** — الرَّحِيمِ / نَسْتَعِينُ, both end in a madd letter before the final consonant; when stopping, 2/4/6 counts apply.
- **Example: An-Nas 114:1** — بِرَبِّ النَّاسِ (stopping on النَّاسِ, alif madd before sākin seen).
- Source: riwaqalquran.com/blog/types-of-madd; alimaanonline.com.

### 4.5 Madd Lāzim (necessary/obligatory madd)
- **Definition:** A madd letter is followed by a **permanent** (non-incidental) sukūn — either a genuine sukūn or a shaddah — within the same word, in all recitation states (connected or stopped).
- **Duration: 6 counts, uniformly** (the one case with no scholarly disagreement on count — "lāzim" = mandatory).
- **Subtypes:**
  - *Kalimī Muthaqqal* (word-based, heavy): madd letter + shaddah in same word. **Example: Al-Fatiha 1:7 — الضَّالِّينَ** (alif + doubled lam/shaddah) — the textbook example cited across sources.
  - *Kalimī Mukhaffaf* (word-based, light): madd letter + plain sukūn, no shaddah. Extremely rare — occurs in only 2 places in the whole Quran, both in **Surah Yunus 10:51 and 10:91** (آلْآنَ) — outside the hifz-10 set; note this as a "seen but not drilled" rule for the course.
  - *Ḥarfī Muthaqqal / Ḥarfī Mukhaffaf*: occur only in the disconnected letters (al-muqaṭṭa‘āt) that open certain surahs (e.g. الم، حم) — not relevant to al-Fatiha or surahs 105–114, since none of those surahs open with muqatta'at letters. Skip for this course's example set.
- Sources: tajweed.us/tajweed-rule/lesson-3-maddi-lazim; riwaqalquran.com/blog/types-of-madd; ilmify.app/blog/madd-rules-tajweed-complete-guide.

## 5. Lām of Allah (Lām al-Jalālah) — Tafkhīm / Tarqīq

- **Definition:** The lām in the word اللَّه (and derivatives like لِلَّه) is the one letter besides ر whose thickness/thinness changes by context; every OTHER lām in the Quran is always light (tarqīq).
- **Tafkhīm (heavy) condition:** the lām is preceded by a letter carrying **fatḥah or ḍammah**.
  - **Example: Al-Fatiha 1:2** — الْحَمْدُ لِلَّهِ? — note: here the letter before the lām of Jalalah is itself a lām carrying **kasrah** (لِ-لَّه), so this is actually the *tarqīq* case (see below); the more standard tafkhīm example is **رَسُولُ اللَّهِ** (Al-Fatiha does not contain this phrase) or **قُلْ هُوَ اللَّهُ أَحَدٌ (Al-Ikhlas 112:1)** — the letter before Lam al-Jalalah is و with ḍammah (هُوَ اللَّهُ) → tafkhīm.
- **Tarqīq (light) condition:** the lām is preceded by a letter carrying **kasrah** (original or incidental).
  - **Example: Al-Fatiha 1:2** — الْحَمْدُ لِلَّهِ: the lām before Lam al-Jalalah carries kasrah → tarqīq.
  - **Example: An-Nasr 110:1** — نَصْرُ اللَّهِ: ر carries ḍammah → tafkhīm (cross-check: this is actually a tafkhīm example, listed here for contrast).
- Sources: tareequljannah.com/blogs/tafkeem-and-tarqeeq-rules-in-tajweed (Lam al-Jalalah section); tajweedrules.com/2015/05/lesson-18rules-of-laam-in-name-of.html; abouttajweed.com/tajweed-rules/53-tafkheem-and-tarqeeq.

## 6. Rā' (ر) — Tafkhīm / Tarqīq

This is the most condition-heavy rule in tajweed; used as an oral-quiz staple per the spec's Final Checkpoint test #3.

### Tafkhīm (heavy) — obligatory when:
1. Rā' carries **fatḥah**. Example: **Al-Fatiha 1:1** — الرَّحْمَٰنِ (ر with fatḥah).
2. Rā' carries **ḍammah**. Example: **Al-Kafirun 109:6-adjacent, or generally رُسُلٌ** (outside hifz set — use as a supplementary drill word).
3. Rā' is **sākin, preceded by fatḥah or ḍammah**. Example: **Al-Fatiha 1:1** — الرَّحِيمِ has ر with kasrah (not this case); better: **Al-Fil 105:1** — بِأَصْحَابِ الْفِيلِ contains no sakin ra; use classic **مَرْيَمَ** (Maryam) as the standard textbook illustration (sakin rā' preceded by fatḥah on ي... actually preceded by fatḥah on م, sakin ر after that? verify letter sequence before use in slides).
4. Rā' is **sākin, preceded by an incidental (‘āriḍ) kasrah** (i.e., the kasrah only appears because of hamzatul-waṣl connection rules, not the word's true root vowel). Example (classic): ارْجِعِي.
5. Rā' is **sākin, preceded by an original kasrah, but followed (within the same word) by one of the 7 isti‘lā' (elevated/heavy) letters** خ ص ض ط ظ غ ق **carrying fatḥah or ḍammah** — this is a fixed, closed list of just 5 words in the entire Quran:
   - قِرْطَاسٍ (Al-An'am 6:7)
   - إِرْصَادًا (At-Tawbah 9:47)
   - فِرْقَةٍ (At-Tawbah 9:25)
   - مِرْصَادًا (An-Naba' 78:21)
   - لَبِالْمِرْصَادِ (Al-Fajr 89:14)
   (None of these 5 fall inside al-Fatiha or surahs 105–114 — flag as a stand-alone "5 exception words" drill card, not tied to hifz surahs.)

### Tarqīq (light) — obligatory when:
1. Rā' carries **kasrah**. Example: no bare-kasrah rā' occurs in al-Fatiha's core text at word-medial position within the hifz-10 set at a glance — pull illustrative word from wider Quran, e.g. رِزْقًا (Al-Baqarah 2:3, outside hifz set) or من الأمثلة العامة: مَرِيجٍ.
2. Rā' is **sākin, preceded by an original kasrah, with NO isti‘lā' letter following**. Example (classic): فِرْعَوْنَ.
3. Rā' is **sākin, preceded by a sākin yā'** (softness of ي transfers). Examples: خَيْرٌ, بَصِيرٌ (in pause).

### Permissible (both wajh valid), for advanced awareness only:
- Rā' sākin after a sākin isti‘lā' letter that is itself preceded by kasrah, e.g. مِصْرَ, الْقِطْرِ (Saba').
- Rā' sākin, original kasrah + a maksūr (kasrah-bearing, not fatḥah/ḍammah) isti‘lā' letter, e.g. فِرْقٍ (Ash-Shu'ara 26:63).

**Recommendation for this course:** Because al-Fatiha and surahs 105–114 do not happen to contain the rarer edge-case rā' words, teach the two baseline rules (fatḥah/ḍammah → heavy; kasrah → light) using in-set examples from al-Fatiha's رَحْمَٰن / رَحِيم / رَبّ, then introduce the 5-word isti‘lā' exception list and the sākin-rā' cases as a separate reference card sourced from outside the hifz set, explicitly labeled "beyond your memorized surahs" so the student isn't confused about where the words come from.

Sources: burujacademy.com/blog/rules-of-raa-in-tajweed (fullest structured breakdown found, cross-checked against shaykhi.com/blog/rules-of-raa and kalimah-center.com/the-rules-of-letter-raa); tareequljannah.com (general tafkheem/tarqeeq framing); abouttajweed.com/tajweed-rules/53-tafkheem-and-tarqeeq (Lam/Ra series, though the Ra-specific sub-page did not load full content during this research pass — re-verify against schools.macnet.ca/alotrojah "Chapter 1: Tafkheem and Tarqeeq" PDF, link found but not fully fetched: https://schools.macnet.ca/alotrojah/wp-content/uploads/sites/10/2019/10/10-Tafkhem-_-Tarqeq-L2A-E_compressed.pdf).

## 7. Waqf (stopping) signs — basic set

| Sign | Name | Meaning |
|---|---|---|
| م | Meem (waqf lāzim) | **Must** stop — continuing changes/obscures the intended meaning. |
| لا | Lā (waqf mamnū‘) | **Must not** stop — stopping here can distort meaning (in some cases toward a meaning bordering on kufr if taken out of context). |
| ج | Jeem (waqf jā'iz) | **Optional** — stopping or continuing both fine. |
| صلى | Ṣād-Lām (waṣl awlā) | Permitted to stop, but **continuing is preferred**. |
| قلى | Qāf-Lām (waqf awlā) | Permitted to continue, but **stopping is preferred**. |
| س / سكتة | Seen / Saktah | Brief pause **without breathing**, then continue — occurs in only a handful of fixed spots in the whole Quran. |
| ∴ ∴ (three dots twice) | Mu‘ānaqah | Stop at ONE of the two marked spots, not both (paired alternation marks). |

- **Course scope note:** the spec explicitly limits Phase 3 to "waqf/stopping basics," excluding advanced waqf. This table (Meem, Lā, Jeem, Ṣād-Lām, Qāf-Lām, Sakta) is the right basic set; skip the rarer marks (mu‘anaqah, qad qeela) for v1.
- Sources: quranreading.com/blog/rules-and-signs-of-stopping-waqf; equrancoaching.com/tajweed-guide/waqf-ibtida/stopping-signs; bayanulquran-academy.com/tajweed-symbols-in-the-quran (18 symbols, fullest list found); quranforkidsonline.wordpress.com/2020/03/19/rules-regarding-waqf-signs-of-stopping-the-quran.

## 8. Color-coded mushaf convention (Dar Al-Maarifah)

### 8.1 What Dar Al-Maarifah is
Dar Al-Maarifah (Beirut-based Islamic publisher) states it **holds the patent on the "Color Coded Tajweed Quran"** concept — coloring the specific letter(s) inside a word that carry a tajweed rule, with a **legend printed at the bottom of every page** and a **~27-page rules supplement** at the back explaining the system in detail. Their product line covers Arabic-only, and Arabic + English/French/German/Russian/Chinese/Spanish translation-transliteration editions, in multiple sizes, plus rarer riwayat (Warsh, Qaloon, Douri) alongside the default Hafs.
- Source (company/product claim of patent + page-legend description): alquranonline.com/color-coded-tajweed.html

### 8.2 Color-to-rule mapping (converged across the two most detailed independent sources)
| Color | Rule |
|---|---|
| **Red** | Madd (elongation) — letters requiring lengthened vocalization |
| **Green** | Ghunnah (nasalization) — noon/meem with shaddah, idgham-with-ghunnah, ikhfa, iqlab |
| **Dark blue** | Tafkhīm (emphatic/heavy pronunciation, e.g. heavy rā', lām of Allah when heavy, the 7 isti'la letters) |
| **Light/medium blue** | Qalqalah (echoing/bouncing plosive letters ق ط ب ج د when sākin) |
| **Gray** | Silent letters (letters written but not pronounced, e.g. the silent alif in و ا at the end of certain third-person plural verbs) |

- This mapping is consistent between **alquranonline.com/color-coded-tajweed.html** and **easyquran.com/en/tajweed-quran-colors-roles** (both independently describe Red=madd, Green=ghunnah, Blue split into dark/light for tafkheem vs qalqalah, Gray=silent).
- **Conflicting secondary source found:** gatewaytoquran.com/color-coded-quran states Red=Ghunnah and Green=heavy letters — the **reverse** of the mapping above — and explicitly caveats "different publishers may use different color schemes." Treat this as evidence that **color schemes are not universally standardized across all tajweed-mushaf publishers**; Dar Al-Maarifah's own scheme (as converged on above) should be the one the course teaches, since the spec's end-goal 4 references "a standard color-coded tajweed mushaf" generically and Dar Al-Maarifah is the most widely distributed and most-patent-asserting example.
- **28 rules total** are claimed to be encodable via these 3 (or 5, counting the two blues and gray separately) color categories, per alquranonline.com's own description of the system, with "optional pause spaces" for waqf marks layered separately (not part of the tajweed-rule color coding itself).

### 8.3 Recommendation for this course
1. **Do not re-host or reproduce Dar Al-Maarifah's actual page images or proprietary color-key artwork** — it is described as patented. The course must build its **own** independent color-span implementation in the Next.js renderer, using the **same conceptual color-to-rule mapping** (red=madd, green=ghunnah, dark-blue=tafkheem, light-blue=qalqalah, gray=silent) so that end-goal 4 ("read from a standard color-coded tajweed mushaf, knowing what each color demands") transfers directly to a real physical Dar Al-Maarifah mushaf if/when the student buys one, without copying any proprietary layout, artwork, or the specific typeset/legend text from the printed book.
2. Verify the final mapping visually against the free Internet Archive scan (§8.1) before shipping Phase 3 slide decks, since third-party paraphrase pages disagree with each other (see §8.2 conflict) and only the physical/scanned book is authoritative.
3. Map rules to colors in-app per the spec's instruction ("each rule is mapped to its standard color-mushaf color the day it is taught") in this teaching order: madd (red) → ghunnah/noon+meem rules (green) → qalqalah (light blue) → tafkheem/lam-of-Allah/ra (dark blue) → silent letters (gray) → waqf marks (separate, non-color glyph layer).

## 11. Summary recommendations for the course build

1. **Rule teaching order** should follow the spec's listed sequence (noon sakinah/tanwin → meem sakinah → qalqalah → madd family → lam of Allah/ra → waqf), which also matches the natural difficulty ramp found across every source surveyed.
2. **Lead every rule's first example from al-Fatiha or surahs 105–114** where a clean instance exists (confirmed for: izhar halqi, idgham with/without ghunnah, ikhfa haqiqi, ikhfa shafawi, izhar shafawi, qalqalah, madd tabee'i, madd muttasil, madd munfasil, madd 'aarid, madd lazim kalimi muthaqqal, lam of Allah tafkheem/tarqeeq, rā' fatha/dammah-heavy). For the 3 rules with **no clean in-set instance** (iqlab, idgham shafawi/mithlayn, and the 5 rā' isti'la-exception words), explicitly source the drill example from elsewhere in the Quran and label it in the lesson content as "reference example, not from your memorized surahs" so the student isn't confused about where a word came from.
3. **Color key**: implement red=madd, green=ghunnah, dark-blue=tafkheem, light-blue=qalqalah, gray=silent as CSS classes/spans, matching the Dar Al-Maarifah convention (majority-source consensus, §8.2) — but verify visually against the Internet Archive scan before finalizing, since one secondary source inverted red/green.
4. **Every example word/ayah must be pulled from the verified Tanzil/QUL Uthmani text**, never retyped from this document or any cited blog — this doc is a rule/citation map, not a copy-source.
5. **Ra' and lam-of-Allah** should be taught with the two baseline conditions first (works for every case inside the hifz set) and the rarer edge cases (5 isti'la exception words, incidental-kasrah cases) taught as a supplementary reference card, since the checkpoint test #3 (oral quiz "naming/explaining rules") only requires the student to *explain* rules, not necessarily recite the 5 exception words from memory.
