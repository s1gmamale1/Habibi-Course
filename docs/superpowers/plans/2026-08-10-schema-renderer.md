# Tajweed Schema & Coloured-Span Renderer (Sub-project C) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the content schema so a tajweed lesson is expressible, and build the renderer that paints rule-coloured Qur'anic text without breaking Arabic shaping.

**Architecture:** Five new discriminated-union slide kinds join `SlideSchema`. A `TajweedText` React component consumes the pre-flattened spans generated by Sub-project B and emits one `<span>` per segment, styling **only** `color` and `text-decoration` so the shaping engine keeps joining letters across element boundaries. Colour is one channel among four — underline style, tap-for-name, and isolate mode carry the same information redundantly.

**Tech Stack:** Zod · React 19 · Next.js 16 (static export) · Tailwind v4 · Vitest + @testing-library/react

## Global Constraints

- **Only `color` and `text-decoration` may be set on a rule span.** Any `display`, `position`, `transform`, `margin`, `padding`, `font-size` or `font-family` on a span forces a new formatting context and re-breaks Arabic letter joining. This is not a style preference; it is a correctness constraint.
- **Never emit whitespace between spans.** JSX and prettier will happily insert newlines between adjacent elements; those become real spaces mid-word. Build children as an array, not as multi-line JSX.
- **Colour is never the only channel.** 14 rules cannot be encoded in colour alone — categorical colour tops out around 8–10 distinguishable hues, fewer under deuteranopia (~8% of males), and on this app's `--bg-velvet: #08070d` background `#000EBC` scores 1.71 contrast, which is unreadable. Every rule span must also carry an underline style, an accessible name, and be reachable via isolate mode.
- **Family B is the default palette** (matches the Quranly app the owner uses: red = qalqalah, blue = madd). Family A (Dar al-Ma'rifah, red = madd) ships as a toggle.
- **Accessibility:** the container carries the plain ayah in `aria-label`; decorative per-rule spans are `aria-hidden`. Otherwise a screen reader announces the ayah in fragments.
- `src/content/schema.ts` is the single source of truth. Content is validated at build time.
- **Another session may be editing `content/` and `src/games/`.** Coordinate before touching either; this plan only needs `src/content/`, `src/components/`, and `src/app/globals.css`.
- Commits: `<type>(<scope>): <description>`. **No `Co-Authored-By` trailer.**

```tsx
"use client";
import { PALETTE_B, PALETTE_A, RULE_META, UNDERLINE, type RuleId } from "@/content/tajweed";

export type Span = { start: number; end: number; rules: string[] };

export function TajweedText({
  text, spans, palette = "B", isolate, onRuleTap,
}: {
  text: string; spans: Span[]; palette?: "A" | "B";
  isolate?: RuleId | null; onRuleTap?: (rule: RuleId) => void;
}) {
  const colours = palette === "A" ? PALETTE_A : PALETTE_B;
  const children: React.ReactNode[] = [];
  let cursor = 0;

  const pushPlain = (to: number) => {
    if (to > cursor) children.push(text.slice(cursor, to));
    cursor = to;
  };

  for (const span of spans) {
    if (span.start < cursor) continue; // defensive: spans must be disjoint
    pushPlain(span.start);
    const primary = span.rules[0] as RuleId;
    const meta = RULE_META[primary];
    const dimmed = Boolean(isolate) && !span.rules.includes(isolate as string);
    children.push(
      <span
        key={span.start}
        data-rule={primary}
        data-dimmed={dimmed ? "true" : undefined}
        aria-hidden="true"
        onClick={onRuleTap ? () => onRuleTap(primary) : undefined}
        style={{
          color: colours[primary],
          textDecorationLine: meta ? "underline" : undefined,
          textDecorationStyle: meta
            ? (UNDERLINE[meta.family] as React.CSSProperties["textDecorationStyle"])
            : undefined,
          opacity: dimmed ? 0.25 : undefined,
        }}
      >
        {text.slice(span.start, span.end)}
      </span>,
    );
    cursor = span.end;
  }
  pushPlain(text.length);

  return (
    <span className="tajweed-text quran" dir="rtl" lang="ar" aria-label={text} role="text">
      {children}
    </span>
  );
}
```

**Why `children` is an array and not JSX:** JSX with newlines between elements inserts real whitespace into the text run, which appears as spaces mid-word in Arabic. Building an array sidesteps this entirely.

**Why only `color`, `text-decoration` and `opacity`:** all three are paint-only properties. They do not create a new formatting context, so HarfBuzz continues shaping across the span boundary and letters stay joined.
