## Objectives

- Student can read any cell of the full 84-cell grid (28 letters × 3 harakat) on sight, fully randomized, with zero major (Jali-tier) errors.
- Student can decode 2–3 syllable combinations built from familiar letters and all 3 harakat, including combinations not seen before (a genuine transfer/fluency test).
- Student and teacher jointly know, going into Checkpoint 1, exactly which specific letters/sounds remain weak (Khafi-tier) so revision time isn't wasted on already-solid material.

## Hook

Tell her at the start that today is a rehearsal for Checkpoint 1, and that **the rehearsal does not count.**

An adult learner who discovers mid-session that she is being assessed will read defensively for the rest of it. Saying it upfront turns the same activity into information she wants: this is what the real thing looks like, and here is what would have gone wrong.

## What they already know

Everything in Phase 1 — 28 letters, four positional forms, the six non-joiners, and the three short vowels. This is the first session that asks for all of it at once, unlabelled.

## Teaching sequence

### 1. Mock Checkpoint 1 run-through

- Teacher runs the actual Checkpoint 1 test script, live, treating it as a rehearsal — logs results on the real rubric sheet.
- This mirrors the qaida tradition's own consolidation step, so the real checkpoint feels familiar rather than high-stakes-novel.

### 2. Joint debrief

- Teacher and student review the rubric sheet together.
- Agree on which 1–2 areas (if any) need a few extra days of home practice before the real checkpoint.

### 3. What to expect at the real Checkpoint 1

- Same test script you just rehearsed: warm-up recognition pass, makhraj (where the sound is born in your mouth or throat) spot-check, positional reading, vowel grid spot-check, syllable transfer test, wrap-up.
- A failed checkpoint never means restarting Phase 1 — it triggers targeted revision of only the specific weak unit(s), then a retest.

**In plain terms:** Nothing new. Today just puts the whole of Phase 1 together at once so you find out what is shaky while it still costs nothing.

## Drills

**Full 84-cell mixed grid reveal.** Read each cell aloud as it's revealed — all 3 vowels interleaved per letter (أَ إِ أُ, بَ بِ بُ, تَ تِ تُ … through ي), not organized vowel-then-letter anymore.

**Guided grid drill, quarter 1 (cells 1–21).** Read each cell aloud in order.

**Guided grid drill, quarter 2 (cells 22–42).** Read each cell aloud in order.

**Guided grid drill, quarter 3 (cells 43–63).** Read each cell aloud in order.

**Guided grid drill, quarter 4 (cells 64–84).** Read each cell aloud in order.

**2-syllable combinations.** Read each as two connected voweled cells in sequence (abstract decoding practice, not vocabulary-taught-for-meaning).

**3-syllable combinations.** Read each as three connected voweled cells in sequence, extended by one more cell. Note: قَرَأَ contains a hamza (a small glottal-stop mark) on alif — a light preview only; full hamza-seat rules come later in the course.

**Cold-read set — pure transfer check.** Read each cluster aloud — 4 brand-new syllable combinations you haven't drilled before this lesson.

**Full 84-cell mixed grid.** Read each cell aloud, fatha/kasra/damma interleaved per letter, randomized order — self-quiz.

**2-syllable combinations.** Read each cluster aloud — abstract decoding practice, not vocabulary-taught-for-meaning.

**3-syllable combinations.** Read each cluster aloud. قَرَأَ contains a hamza (a small glottal-stop mark) on alif — a light preview only; full hamza-seat rules come later in the course.

**Cold-read transfer set.** Read each cluster aloud — new, unseen before this lesson.

## Listen-for

The teacher's checklist as it ships. **These are the shipped plain-string form**,
not the structured `ListenForSchema` the tajweed units use — see the banner above.

- Full re-check of every item on the high-risk watchlist accumulated across Phase 1: ح/خ/ه confusion, ص/ض/ط/ظ tafkheem, ع vs ء, غ vs خ vs ق, ق vs ك, ذ/ز/ض "D→Z" collapse pattern, ر tongue-tap quality, fatha/kasra/damma timing (no lengthening into madd).
- During the mock checkpoint run-through specifically: distinguish Jali (wrong letter/sound entirely — hard-fail signal) from Khafi (right letter/sound but quality slightly off — flag-and-practice signal), using the rubric in the Checkpoint 1 Kit, so the debrief conversation is concrete rather than vague ("you're basically ready" vs. "here are the 3 specific cells to drill").
- Syllable-transfer set specifically: does the student sound out letter-by-letter still, or read the combination fluently? Either is fine at this stage, but note it for Phase 2 pacing.

## Teacher script

- Open with the full 28-letter shuffle as a baseline confidence check before revealing the 84-cell mixed grid.
- Since no vetted 'hear the whole grid' video is wired in for this course yet (candidates remain unverified/audition-required per verified-resources.md §4), demonstrate the full 84-cell interleaved grid live yourself before the four guided quarters.
- Run all four guided quarters (21 cells each) before introducing any syllable combinations — full-grid fluency first, then multi-cell decoding.
- Introduce 2-syllable combinations before 3-syllable ones, then the cold-read transfer set — the cold-read items are the one genuinely unseen-material check, so observe without prompting.
- Run the actual Checkpoint 1 test script live as a rehearsal, logging results on the real rubric sheet, exactly as the real checkpoint will be scored.
- Close with the joint debrief — name the 1–2 specific weak spots together with the student, never a vague 'you're basically ready.'

## Homework

In the student's notebook: today's marked syllables written 4 full rows, saying each aloud while writing, then memorized. Full 84-cell grid, randomized self-quiz, daily (also reviews every letter learned so far). Re-read all syllable combinations (2- and 3-syllable) from today, 3× through. Focused extra practice only on whatever 1–2 specific weak spots the joint debrief identified — not a blanket repeat of everything. Rest/consolidate the day immediately before the real Checkpoint 1 session (light review only, no new drilling). No printed sheets.

**Daily checklist:**

- Write today's marked syllables 4 rows each in your notebook, saying each syllable aloud as you write
- Full 84-cell grid, randomized self-quiz, daily
- Re-read all syllable combinations (2- and 3-syllable) from today, 3× through
- Focused extra practice only on whatever 1–2 specific weak spots the joint debrief identified
- Rest/consolidate the day immediately before the real Checkpoint 1 session (light review only, no new drilling)
